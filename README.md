# LingoLooper Growth Audit

**Live → https://eddieatadapty.github.io/lingolooper-flow-rebuild/**

Five ideas to turn more LingoLooper users into subscribers, each built into a clickable version of LingoLooper's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Let them speak in the first minute, before any price | +5–15% CR to purchase |
| 02 | Ask the one question the ad left open, then use the answer | +10–15% CR to purchase |
| 03 | Put your 4.8 stars and your reviews where they pay | +5–10% CR to purchase |
| 04 | Make the yearly saving impossible to miss | +5–15% ARPU |
| 05 | Catch the people who close the paywall | +5–10% CR from paywall closers |

Every price, rating and feature comes from LingoLooper's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for LingoLooper. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
